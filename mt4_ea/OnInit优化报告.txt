🎯 问题: EA 挂载时卡死 1-2 分钟
🔍 原因: OnInit() 同步执行大量阻塞 HTTP 请求
✅ 修复: 将所有 HTTP 调用移至 OnTick() 异步处理

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 根本原因分析

OnInit() 末尾同步执行的阻塞调用链:

  RegisterAccount()  → HTTP POST  最多 10.5s  (2次重试 × 5s超时)
     ↓
  SendHeartbeat()    → HTTP POST  最多 10.5s
     ↓
  SendAllBars()      → HTTP POST  × 7周期 × N品种  最多 73.5s ← 主凶
     ↓
  SendPositions()    → HTTP POST  × N品种  最多 10.5s

  总计: 约 105 秒（服务端不可达时）

问题:
  ❌ OnInit 是 MT4 主线程同步调用，阻塞期间 UI 冻结
  ❌ 用户无法查看日志、无法操作图表
  ❌ 误以为 EA 崩溃，强制关闭

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 修复方案

修改前:
  ┌─────────────────────────────────────────────────┐
  │ OnInit()                                        │
  │   ├─ 配置检查                                   │
  │   ├─ RegisterAccount()    [阻塞 10.5s]         │
  │   ├─ SendHeartbeat()      [阻塞 10.5s]         │
  │   ├─ SendAllBars()        [阻塞 73.5s] ← 主凶  │
  │   └─ SendPositions()      [阻塞 10.5s]         │
  │                                                 │
  │   用户体验: 界面冻结 105 秒 😱                  │
  └─────────────────────────────────────────────────┘

修改后:
  ┌─────────────────────────────────────────────────┐
  │ OnInit()                                        │
  │   ├─ 配置检查                                   │
  │   └─ Print("⏳ 等待首次 Tick...")  [<0.1s]     │
  │                                                 │
  │   用户体验: 瞬间完成 ⚡                         │
  └─────────────────────────────────────────────────┘
           ↓
  ┌─────────────────────────────────────────────────┐
  │ OnTick() (首次 Tick，<1秒后)                    │
  │   ├─ RegisterAccount()    [后台异步]           │
  │   ├─ SendHeartbeat()      [后台异步]           │
  │   ├─ SendAllBars()        [后台异步]           │
  │   └─ SendPositions()      [后台异步]           │
  │                                                 │
  │   用户体验: UI 流畅，日志实时可见 ✅            │
  └─────────────────────────────────────────────────┘
