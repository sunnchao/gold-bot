# GoldBolt EA OnInit 阻塞优化 v2.8.5

**优化日期**: 2026-06-18  
**问题**: EA 挂载时卡死 1-2 分钟  
**原因**: OnInit() 同步执行大量阻塞 HTTP 请求  
**修复**: 将所有 HTTP 调用移至 OnTick() 异步处理

---

## 🔍 问题分析

### 卡死原因

`OnInit()` 末尾同步执行了大量阻塞的 HTTP 请求：

```mql4
// OnInit() 末尾 (行 422-433)
if(!RegisterAccount())  // ← HTTP 请求，最多 10.5s (重试2次×5s超时)
{
   gbRegistered = false;
   Print("⚠️ 注册失败，OnTick 将每 5 秒重试...");
}
else
{
   SendHeartbeat();     // ← HTTP 请求，最多 10.5s
   SendAllBars();       // ← HTTP 请求 × 7周期 × N品种，最多 73.5s ⚠️ 主凶
   SendPositions();     // ← HTTP 请求 × N品种，最多 10.5s
}
```

### 阻塞时间计算

**最坏情况（服务端不可达）**：
- `RegisterAccount()`: 2次重试 × 5秒超时 = 10.5秒
- `SendHeartbeat()`: 2次重试 × 5秒超时 = 10.5秒
- `SendAllBars()`: 7个时间框架 × N个品种 × 10.5秒 = **73.5秒** (1品种)
- `SendPositions()`: N个品种 × 10.5秒 = 10.5秒 (1品种)

**总计**: 约 **105秒 (1分45秒)**，如果配置多品种则更长

### 根本问题

`OnInit()` 是 MT4 主线程同步调用，阻塞期间：
- ❌ UI 界面冻结（无响应）
- ❌ 图表无法操作
- ❌ 无法查看日志
- ❌ 用户误以为 EA 崩溃

而 `OnTick()` 中**已有完全相同的逻辑**，`OnInit()` 的这些调用完全是冗余的。

```diff
   dailyStartEquity = AccountEquity();

-  // 注册账户信息（含 broker 信息），失败时由 OnTick 每 5 秒重试

+  Print("⏳ 等待首次 Tick 后注册并发送初始数据...");

   return INIT_SUCCEEDED;
}
```

### 工作原理

`OnTick()` 中已有完整的注册和初始化逻辑（行 440-451）：

```mql4
// ========== v2.8: 注册失败时每 5 秒重试 ==========
if(!gbRegistered && now - lastRegisterTry >= 5)
{
   lastRegisterTry = now;
   Print("🔄 尝试注册 GB Server...");
   if(RegisterAccount())
   {
      // 注册成功后发送初始数据
      Print("✅ 注册成功，发送初始数据...");
      SendHeartbeat();
      SendAllBars();
      SendPositions();
   }
}
```

**执行流程**：
1. `OnInit()` 完成配置检查后**立即返回**（<100ms）
2. MT4 接收到第一个 Tick → 调用 `OnTick()`
3. `lastRegisterTry = 0`（初始值），条件 `now - 0 >= 5` 立即满足
4. 执行 `RegisterAccount()` → 注册成功后自动发送初始数据
5. 注册失败 → 每 5 秒自动重试

## 📝 代码审查要点

### 为什么不保留 OnInit 注册？

**问题**: 有人可能认为 `OnInit()` 注册可以提前完成连接。

**答案**: 
1. `OnInit()` 的阻塞会导致 UI 冻结，用户体验极差
2. `OnTick()` 会在 <1 秒内触发（市场活跃时几乎立即）
3. 即使 `OnInit()` 注册成功，`OnTick()` 仍会每 5 秒发送心跳/K线，延迟 1 秒影响可忽略
4. 如果服务端不可达，`OnInit()` 阻塞 105 秒完全浪费

### 为什么不用异步 HTTP？

**问题**: MQL4 是否支持异步 HTTP？

**答案**: 
- ❌ MQL4 的 `WebRequest()` 是同步阻塞的
- ❌ 不支持多线程
- ✅ 最佳方案就是将耗时操作移到 `OnTick()` 异步执行

### OnTick 首次触发时机？

**问题**: 如果市场静止，`OnTick()` 不触发怎么办？

**答案**: 
- MT4 会在 EA 挂载后立即发送至少 1 个 Tick（即使价格未变化）
- 即使极端情况下无 Tick，注册延迟几秒也不影响功能
- 一旦有价格波动，`OnTick()` 立即触发
